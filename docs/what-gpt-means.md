# What does GPT stand for?

**GPT** stands for **Generative Pre-trained Transformer**.

- **Generative:** produces content, such as text or code.
- **Pre-trained:** learns patterns from data before later adaptation to tasks.
- **Transformer:** the neural-network architecture used by the model.

Pretraining is distinct from supplying information in a prompt or building a
search index. See [knowledge, training, and retrieval](knowledge-and-training.md).
